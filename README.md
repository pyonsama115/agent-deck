# Agent Deck 🤖🛰️

**Claude Code と OpenAI Codex のセッションを、1ページでゲーム感覚で見守るローカルダッシュボード。**

並行して走らせている AI エージェントが「いま何をしているか」を、ロボットたちの動きで一目で分かるようにします。
ファイルを読んでいれば虫眼鏡で書類を調べ、編集中ならトンカチを振り、サブエージェントを呼べば小さなロボットたちが親ロボットの指示で働きます。

- 依存パッケージなし (Node.js 18 以上だけ)
- 127.0.0.1 だけで待ち受け、データは外部に送りません
- Windows / macOS / Linux

## 起動

```bash
node server.js
```

ブラウザで http://127.0.0.1:8787 を開きます。Windows なら `start.cmd` をダブルクリックでも起動できます。

架空のデータで全部の演出を見るには http://127.0.0.1:8787/?demo=1 を開いてください。

## 画面

| レーン | 入るセッション |
|---|---|
| 🙋 返信待ち | 許可・質問で止まっている / 作業が終わってから15分以内 |
| ⚙️ 進行中 | いま作業している |
| 💤 待機 | しばらく動きがない (終了済みは下にたたんで表示) |

### ロボットの場面

| 作業内容 | 場面 |
|---|---|
| 考え中 | 頭の上の雲で歯車が回る |
| Read / Grep など | 虫眼鏡で書類を調べる |
| Edit / Write / apply_patch | トンカチでコードを打ち込む |
| Bash / シェル | ノートPCでカタカタ、ターミナルが流れる |
| WebSearch / WebFetch | アンテナから電波、地球儀が回る |
| ブラウザ操作 | カーソルがボタンをクリック |
| TodoWrite / plan | ホワイトボードのチェックリスト |
| その他のツール (MCP など) | ベルトコンベアの工場 |
| サブエージェント | 親ロボットがメガホンで指示、ちびロボたちが運ぶ・叩く・打つ・調べる |
| 許可・質問待ち | 看板を立てて手を振ってぴょんぴょん |
| ターン完了 | 旗を振ってトロフィー |
| 待機 | 月夜ですやすや |
| エラー / 中断 | 煙・警告 / 一時停止標識 |

### ゲーム要素

- **XP とレベル**: ツール使用 +2、ターン完了 +25、サブエージェント呼び出し +12。ロボットごとのレベルと、あなたのパイロットレベルが上がります
- **コンボ**: 5分以内に連続でターンが完了すると COMBO
- **実績**: 「3体同時稼働」「夢の共演 (Claude と Codex が同時に作業)」「即レス」など
- **今日の成績**: ターン数・ツール使用数・サブエージェント数・稼働の推移グラフ

### そのほか

- カードをクリックすると詳細とタイムライン (指示・ツール・返答) が開きます
- 「✓ 完了」でセッションを終了済みに移せます (新しい動きがあれば自動で戻ります)
- 返信待ちになるとトースト・効果音・デスクトップ通知・タブのファビコンのバッジで知らせます
- **天気**: エージェントの調子で空模様が変わります (☀️ 快晴: 順調 / ☁️ くもり: 返信待ちあり・使用量60%超 / 🌧️ 雨: 3分以上の待ちが2件・使用量80%超 / ⛈️ 雷雨: エラー・上限到達 / 🌈 コンボや実績で虹 / 夜にターンが終わると流れ星)
- 時間帯で背景と配色が変わります: 朝 (5〜10時)・昼 (10〜16時)・夕方 (16〜19時)・夜。`T` かボタンで固定もできます
- Claude / Codex の使用枠: 枠の種類 (5時間・週) ごとに「使用 ◯% · 残り ◯%」とリセット時刻。上限に達したら解除時刻を表示
- カードの大きさを「大 (場面全体)・中 (ロボットのアップ)・小 (1行)」から選べます (`D` で切り替え)
- 動きが重いときは 🪶 軽量モード (`L`): 背景を間引き、待機中のロボットを止めます。画面外のカードはいつも自動で止まります
- ショートカット: `T` 時間帯 / `L` 軽量モード / `D` 大きさ / `1` `2` `3` 絞り込み / `/` 検索 / `F` フィード / `E` 終了済み / `X` 自動実行 / `S` 効果音 / `A` 実績 / `?` ヘルプ

## データの取り方

| エージェント | ソース | 分かること |
|---|---|---|
| Claude | `~/.claude/sessions/<pid>.json` | 生きているプロセス、busy / idle / waiting |
| Claude | `~/.claude/projects/**/<id>.jsonl` (末尾のみ) | 使用中のツール、最後の発言、モデル、コンテキスト量、コスト |
| Claude | `~/.claude/projects/**/<id>/subagents/` | サブエージェントの数 |
| Claude | `%APPDATA%/Claude/claude-code-sessions` | デスクトップアプリのタイトル、フォーク (サイドチャット)、アーカイブ |
| Claude | `%APPDATA%/Claude/plan-usage-history.json` | 使用率 (デスクトップアプリが時々記録する値。古い5時間枠の値は「不明」と表示) |
| Claude | トランスクリプトの `quotaLimits` | 使用上限に達した枠と解除時刻 |
| Codex | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` | ターン開始/完了、承認待ち、ツール、トークン、使用枠 (`rate_limits` の枠の長さ・使用率・リセット時刻) |
| Codex | `~/.codex/session_index.jsonl` | スレッド名 |
| Codex | `codex app-server` の `account/rateLimits/read` (10分ごと) | 最新の使用枠。モデルは動かさないので無料。`AGENT_DECK_CODEX_POLL_MIN=0` で無効 |
| 両方 | hooks → `POST /hook/claude` `/hook/codex` | 許可待ちなどをより早く正確に検出 |

ログだけでも動きますが、hooks を入れると許可待ちの検出が速く確実になります。
どちらのログ形式も公式には「内部形式で変わりうる」とされているので、バージョンアップで一部が表示されなくなる可能性があります。

## hooks の追加 (任意)

```bash
node install-hooks.js          # 変更内容の確認だけ
node install-hooks.js --apply  # バックアップを取ってから追加
node install-hooks.js --remove # 取り除く
```

- Claude: `~/.claude/settings.json` に `http` 型 hook を追加します。ダッシュボードが止まっていても Claude の動作は止まりません。
- Codex: `~/.codex/hooks.json` に `hooks/codex-hook.js` を呼ぶ hook を追加します。初回は Codex の `/hooks` で信頼 (trust) が必要な場合があります。
- 既存の hooks や Codex の `notify` には触れません。
- このフォルダを移動・削除する前に `--remove` で取り除いてください (Codex の hook はこのフォルダのスクリプトを呼びます)。

## Claude の使用枠をリアルタイムにする (任意・ターミナルの Claude Code のみ)

Claude の使用率を公式に取れるのはステータスラインだけです。`~/.claude/settings.json` に次を追加すると、Claude Code が受け取った最新の使用枠が `~/.claude/agent-deck-usage.json` に保存され、ダッシュボードはそれを優先して表示します (モデルは呼ばないので料金・使用枠の消費はありません)。

```json
"statusLine": { "type": "command", "command": "node \"<このフォルダ>/hooks/claude-statusline.js\"", "refreshInterval": 60 }
```

注意: Claude デスクトップアプリの Code タブではステータスラインが動かないことを確認しています (2026-10 時点)。ターミナルで `claude` を使う場合だけ有効です。

## 設定 (環境変数)

| 変数 | 既定値 |
|---|---|
| `AGENT_DECK_PORT` | 8787 |
| `AGENT_DECK_HOST` | 127.0.0.1 |
| `AGENT_DECK_RECENT_HOURS` | 12 (この時間内に動いたセッションを表示) |
| `CLAUDE_CONFIG_DIR` / `CODEX_HOME` | `~/.claude` / `~/.codex` |

## スマホ・別の PC から見る

既定では自分の PC からしか開けません。外から見たい場合は、認証なしで LAN やインターネットに公開せず、[Tailscale Serve](https://tailscale.com/kb/1312/serve) などで自分の端末だけに公開するのがおすすめです。ダッシュボードにはセッション名や会話の一部が表示されます。

## プライバシー

- 読むのはこの PC 上のログだけで、外部への送信はしません (フォントを Google Fonts から読み込むのみ)
- `data/state.json` に XP・実績・イベント履歴 (セッション名を含む) を保存します。リポジトリには含めないでください (`.gitignore` 済み)
